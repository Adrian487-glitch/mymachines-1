Hva er Git?

Git er et distribuert versjonskontrollsystem som brukes til å spore endringer i kildekode og andre filer over tid

GitHub

Git is designed to be fast and efficient, even with large projects.

Git Bash

Git Bash er et program for Windows som gir deg en ledetekst (terminal) med støtte for både Git-kommander og Unix-likende kommandoer

Basic Bash commands

pwd — Print working directory. Shows your current path.
ls — List directory contents. Lists files and folders.
ls -la — Detailed list. Shows hidden files and file details.
cd [dir] — Change directory. Moves to a specified folder.
cd .. — Move up. Navigates to the parent directory.
cd ~ — Home directory. Instantly returns to your home

Basic Git commands

git init
git add .
git commit -m "Initial commit"
git push
