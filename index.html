Hva er Git?

Git er et distribuert versjonskontrollsystem som brukes til å spore endringer i kildekode og andre filer over tid

Fast

Git is designed to be fast and efficient, even with large projects.

Distributed

Every developer has a complete copy of the repository.

Open Source

Git is free and open source software used by developers around the world.

Basic Git commands

git init
git add .
git commit -m "Initial commit"
git push
